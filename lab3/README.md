# Лабораторная работа №3

Лабораторная №3 запланирована как перенос инфраструктуры CyberNews в Kubernetes. Текущий способ запуска — Docker Compose.

1. Подготовить namespace, Deployments и Services для шести приложений и входящего трафика.
2. Вынести параметры в ConfigMaps и подключить секреты через выбранный механизм кластера.
3. Развернуть PostgreSQL и RabbitMQ с постоянным хранилищем и проверить восстановление после перезапуска.
4. Подключить `/health` и `/ready` как liveness и readiness probes.
5. Сохранить внешний контракт `/api/v1/{service}/` и запустить инфраструктурные проверки в кластере.

Будущие манифесты размещаются в `k8s/`. Архитектура и распределение баз описаны в [документе проекта](../docs/ARCHITECTURE.md).
