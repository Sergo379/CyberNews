# Frontend

Браузерный интерфейс CyberNews на HTML, CSS и JavaScript. Доступен через существующий Gateway по адресу [localhost:8080](http://localhost:8080/).

- `admin/` — отдельная административная панель с дополнительной авторизацией.
- `css/` — общие стили.
- `js/` — клиентская логика и обращения к API Gateway.
- `locales/` — ресурсы интерфейса RU/EN.

Запуск, маршруты, безопасность и браузерные проверки описаны в [руководстве по интерфейсу](../docs/FRONTEND_GUIDE.md).
