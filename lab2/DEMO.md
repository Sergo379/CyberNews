# Демонстрация на защите

## Подготовка до начала

1. Запустите рабочий Compose и выполните `.\scripts\verify-lab2.ps1`. Откройте [главную](http://localhost:8080/), [Swagger Auth](http://localhost:8080/api/v1/auth/docs), [Articles](http://localhost:8080/api/v1/articles/docs) и [Community](http://localhost:8080/api/v1/community/docs). Подготовьте вкладку с [архитектурой](diagrams/architecture.md).
2. Во втором интерактивном PowerShell в корне проекта запустите демонстрационный режим. Он создаёт отдельный проект Compose со случайным именем, временными базами и брокером и публикует Gateway на свободном loopback-порту.

```powershell
.\scripts\smoke-test-stage5.ps1 -Demo
```

3. Введите данные временного Super Admin в скрытых приглашениях CLI. Используйте разные основной и административный пароли. Скопируйте выведенный адрес и обозначьте его для себя как `DEMO_URL`. Оставьте PowerShell в ожидании.
4. В приватном окне на `DEMO_URL` создайте временного читателя. Во втором профиле браузера создайте будущего Moderator, назначьте ему роль через Super Admin и снова войдите как Moderator. На `DEMO_URL/admin/` задайте отдельный пароль. Разнесите сеансы читателя, Moderator и Super Admin по несвязанным профилям браузера. У читателя заранее включите подписку «Исследования». Оставьте одну тестовую жалобу на публикацию для демонстрации.

## Порядок показа

| Время | Что открыть и сделать | Что должно быть видно и что объяснить |
| --- | --- | --- |
| 0:00–0:40 | Открыть [главную CyberNews](http://localhost:8080/) | Проект агрегирует RSS, хранит новости и связывает обсуждение, модерацию и подписки |
| 0:40–1:30 | Открыть [архитектуру](diagrams/architecture.md) | Шесть приложений владеют разной логикой и данными. Nginx маршрутизирует запросы, PostgreSQL хранит данные, RabbitMQ доставляет события |
| 1:30–2:10 | Выполнить `docker compose ps` | Девять контейнеров в состоянии `healthy`. Пояснить отличие доступности процесса от готовности его зависимостей |
| 2:10–2:55 | Показать Swagger Auth, Articles, Community и `Invoke-RestMethod http://localhost:8080/health` | Видны методы, схемы и коды. Gateway сохраняет отдельные префиксы. Запрос к health возвращает JSON |
| 2:55–3:35 | Показать вывод `.\scripts\verify-lab2.ps1` и [схему баз](diagrams/databases.md) | У каждой роли ровно одна база. При этом PostgreSQL один. Межсервисная ссылка — UUID, локальная связь — SQL FK |
| 3:35–4:25 | В рабочей ленте выбрать категорию, применить поиск, открыть статью и ссылку на издателя | Результаты берутся из каталога. RSS без разрешения на полный текст отображается как выдержка и ссылка |
| 4:25–5:35 | На `DEMO_URL` открыть статью от имени временного читателя, добавить комментарий и реакцию, сохранить закладку | Комментарий и счётчики обновятся. Private API отвечают на запросы с JWT текущего аккаунта |
| 5:35–6:50 | В Moderator открыть жалобу или созданный комментарий, указать причину скрытия. В профиле Super Admin показать восстановление и меню RSS | На странице читателя комментарий исчезает, а журнал модерации фиксирует действие. Super Admin видит дополнительные серверные полномочия |
| 6:50–8:25 | В Super Admin создать и опубликовать собственную временную статью в категории «Исследования». Во вкладке читателя открыть `DEMO_URL/notifications` и при необходимости обновить её | Возникает уведомление. Объяснить outbox, подтверждение RabbitMQ, дедупликацию на `event_id` и отсутствие повторной рассылки при редактировании |
| 8:25–9:15 | Открыть [результаты тестов](EVIDENCE.md) и [матрицу](REQUIREMENTS_MATRIX.md) | Показать результаты остановки зависимостей в изоляции, восстановление данных и браузерные проверки |

Для очередей откройте [RabbitMQ Management](http://localhost:15672/) с локальными учётными данными вне захвата экрана или покажите безопасную команду списка очередей из [доказательств](EVIDENCE.md). Management рабочего стека демонстрирует топологию, а уведомление в `DEMO_URL` проходит через отдельный RabbitMQ. Можно вместо Management показать [диаграмму события](diagrams/article-events.md) и тест брокера.

Если внешний RSS временно недоступен, откройте уже сохранённую публикацию рабочего каталога. Для воспроизводимого поиска на стенде введите `Acorn`. Collector там получает RSS/Atom из контролируемых фикстур, поэтому сценарий обсуждения и публикации возможен при недоступном внешнем издателе.

В конце нажмите Enter в терминале демонстрационного режима. Он остановит свой временный проект. На рабочем адресе во время демонстрации используются только операции чтения.
