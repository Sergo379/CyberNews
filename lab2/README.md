# Лабораторная работа №2

Цель работы — подготовить фундамент микросервисного портала CyberNews. Стенд включает шесть приложений FastAPI, единый вход Nginx, PostgreSQL с выделенной базой на сервис и RabbitMQ с интерфейсом управления. Docker Compose собирает и запускает компоненты на Windows 11 с Docker Desktop.

## Запуск

Из корня проекта выполните команды PowerShell.

```powershell
.\scripts\init-env.ps1
docker compose up -d --build
.\scripts\smoke-test.ps1
```

## Результат первого этапа

В стенде реализованы маршрутизация, изоляция PostgreSQL, механизм сохранения состояния брокера и базы, JSON-логирование с идентификатором запроса и проверки доступности. Smoke-тест проверяет готовность шести сервисов через Gateway и сохранность тестовых данных после перезапуска.

Следующие задачи включают авторизацию и роли, сбор RSS, выдачу статей, взаимодействие пользователей, модерацию, уведомления и двуязычный интерфейс. Подробные инструкции приведены в [README](../README.md), границы и API — в [описании архитектуры](../docs/ARCHITECTURE.md).
