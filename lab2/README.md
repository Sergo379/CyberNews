# Лабораторная работа №2

Цель работы — подготовить фундамент микросервисного портала CyberNews. Стенд включает шесть приложений FastAPI, единый вход Nginx, PostgreSQL с выделенной базой на сервис и RabbitMQ с интерфейсом управления. Docker Compose собирает и запускает компоненты на Windows 11 с Docker Desktop.

## Запуск

Из корня проекта выполните команды PowerShell.

```powershell
.\scripts\init-env.ps1
docker compose up -d --build
.\scripts\smoke-test.ps1
.\scripts\smoke-test-stage2.ps1
```

## Результат первого этапа

В стенде реализованы маршрутизация, изоляция PostgreSQL, механизм сохранения состояния брокера и базы, JSON-логирование с идентификатором запроса и проверки доступности. Smoke-тест проверяет готовность шести сервисов через Gateway и сохранность тестовых данных после перезапуска.

## Результат второго этапа

Auth поддерживает регистрацию, вход с JWT, профили, административные сессии и управление ролями и аккаунтами. Moderation поддерживает жалобы, ограничения комментирования и аудит. Снятие ограничений и восстановление аккаунтов доступны Super Admin. Сервисы используют свои базы и миграции Alembic. Автоматические проверки разворачивают изолированный стенд и проверяют сценарии через Gateway, включая сохранность данных после перезапуска.

## Результат третьего этапа

Collector загружает три публичных RSS-источника при запуске и каждые 30 минут. Он поддерживает ручной сбор, хранит историю и импортирует нормализованные статьи по закрытому API. Articles хранит каталог в собственной базе, поддерживает дедупликацию, категории, фильтры и поиск, а также публикацию и редактирование собственных статей. Права внешнего контента проверяются через подтверждённую политику источника.

Интеграционный скрипт `scripts/smoke-test-stage3.ps1` использует локальные RSS/Atom-фикстуры в отдельном Compose-проекте. Рабочий стек проверяется отдельно на реальных источниках.

## Результат четвёртого этапа

Community поддерживает комментарии, реакции и избранное. Moderation проверяет цели жалоб, скрывает и восстанавливает комментарии с идемпотентными командами и аудитом. Articles сохраняет события первой публикации в transactional outbox. Notifications создаёт внутренние уведомления подписчикам после получения события RabbitMQ. Скрипт `scripts/smoke-test-stage4.ps1` проверяет взаимодействие на отдельном стенде с реальным брокером.
